I like [Warp](https://www.warp.dev)'s terminal, but I spend my day in VS Code and kept switching
windows. Since Warp [open-sourced their client](https://github.com/warpdotdev/warp), I built
**Warp Terminal for VS Code**: an unofficial fork of Warp that runs as a tab in VS Code's bottom panel, right
next to the built-in terminal.

What you get:

- Warp's blocks, input editor, completions and history search
- tabs and splits that come back across VS Code windows and restarts
- shells that keep running when you reload the window, like VS Code's own terminal
- `#` AI command search and Next Command with your own OpenRouter key

Warp's account, cloud and agent features are hidden, so no sign-in is needed.

**Install:** [Warp Terminal for VS Code on the Marketplace](https://marketplace.visualstudio.com/items?itemName=felixkrueckel.panelwarp)
(macOS and Linux). **Source:** [github.com/felkru/panelwarp](https://github.com/felkru/panelwarp).
